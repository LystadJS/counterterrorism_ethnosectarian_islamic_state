# Rights, licensing, and reuse

This repository combines original code and writing with source-derived research artifacts and third-party documentation. A single blanket license can therefore create ambiguity if applied without review.

## Current repository-level position

**No blanket open-source or Creative Commons license is granted by this refactor.** Unless a file states otherwise, original repository material remains subject to ordinary copyright held by its author, and third-party material remains subject to the rights and terms of its original source.

Public availability on GitHub should not be interpreted as permission to redistribute restricted source data or third-party documents.

## Before a tagged release

A deliberate licensing decision should separate at least the following classes:

| Material | Licensing decision to make |
|---|---|
| Original R code | Choose an explicit software license if reuse is intended (for example MIT, BSD, Apache-2.0, or another suitable license) |
| Original prose/documentation | Decide whether to reserve rights or use an appropriate Creative Commons license |
| Original figures | Decide whether figures are separately reusable and under what attribution terms |
| Derived datasets | Confirm redistribution rights under every underlying source-data agreement before licensing |
| Third-party data/docs | Preserve original source terms; do not relicense material you do not control |

## Source-data terms

The analytical workflows reference external resources including GTD, ESOC-associated spatial/ethnicity materials, and LandScan. Their licenses, EULAs, registration terms, or citation requirements remain controlling.

See `DATA.md` for the project's data-governance checklist.

## Citation is not a license

`CITATION.cff` provides scholarly attribution metadata. It does not grant permission to reuse content that otherwise requires a license or source-data authorization.
